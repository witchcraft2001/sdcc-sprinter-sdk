# Введение

## Что такое SDCC Sprinter SDK

SDCC Sprinter SDK -- кроссплатформенный набор инструментов для разработки программ на языке Си для компьютера **ZX Sprinter**. SDK предоставляет стандартную библиотеку языка Си и API для работы с аппаратным обеспечением Спринтера, позволяя писать, компилировать и отлаживать программы на современных ОС (macOS, Linux, Windows).

## Целевая платформа

**ZX Sprinter** -- отечественный компьютер на базе процессора Z80:

- Процессор: **Z80** (тактовая частота 7 или 21 МГц)
- ОС: **Estex DSS** (Disk SubSystem)
- ОЗУ: 4 МБ (разбита на страницы по 16 КБ)
- Видео: текстовые режимы 40x32 / 80x32, графические 320x256 (256 цветов), 640x256 (16 цветов)
- Звук: AY-3-8910, Covox DAC
- Ввод: PS/2 клавиатура, мышь
- Накопители: IDE HDD, дискеты

## Компилятор SDCC

SDK использует компилятор **SDCC** (Small Device C Compiler):

- **Бесплатный** и с открытым исходным кодом
- **Кроссплатформенный**: работает на macOS, Linux, Windows
- Поддерживает стандарты **C89/C99** (подмножество)
- Генерирует код для Z80, а также для других 8-битных процессоров
- Активно развивается и имеет большое сообщество
- Сайт: https://sdcc.sourceforge.net/

## Сравнение с SOLID C

**SOLID C** (2004) -- оригинальный Си-компилятор для ZX Sprinter, созданный для работы непосредственно на самом Спринтере.

| Характеристика | SOLID C | SDCC Sprinter SDK |
|----------------|---------|-------------------|
| Платформа разработки | ZX Sprinter | macOS / Linux / Windows |
| Синтаксис | C89 + расширения K&R | C89 / C99 (ANSI) |
| Типы данных | int=16, long=32, float | int=16, long=32, нет float |
| Динамическая память | malloc/free | нет |
| Стандартная библиотека | stdio, dos, conio, io, mouse, types | stdio, stdlib, string, ctype, conio + sprinter API |
| Модульная линковка | нет (вся библиотека) | да (103 модуля, селективная) |
| Стоимость | бесплатный | бесплатный |
| Исходный код | закрытый | открытый |
| Поддержка asm | inline asm (Sprinter) | inline asm (SDCC синтаксис) |
| Pragma | `#pragma nonrec/recursive` | не нужны (автоматически) |

Подробное руководство по переносу программ из SOLID C приведено в главе [07 -- Перенос с SOLID C](07_перенос_с_solidc.md).

## Возможности SDK

### Стандартная библиотека C

SDK предоставляет знакомые заголовки стандартной библиотеки:

- `<stdio.h>` -- ввод-вывод: printf, fopen, fread, fwrite и др.
- `<stdlib.h>` -- утилиты: exit, atoi, rand, abs
- `<string.h>` -- строки: strlen, strcpy, strcmp, memcpy и др.
- `<ctype.h>` -- классификация символов: isalpha, isdigit, toupper и др.
- `<conio.h>` -- консольный ввод-вывод: getch, kbhit, clrscr, gotoxy

### Sprinter API

Прямой доступ к аппаратуре через специализированные заголовки:

- `<sprinter/dss.h>` -- вызовы ОС DSS (файлы, клавиатура, консоль, память)
- `<sprinter/bios.h>` -- вызовы BIOS (палитра, пиксели, порты)
- `<sprinter/video.h>` -- управление видеорежимами
- `<sprinter/mouse.h>` -- драйвер мыши
- `<sprinter/ports.h>` -- определения аппаратных портов
- `<sprinter/types.h>` -- целочисленные типы (u8, u16, u32, i8, i16, i32)

### Селективная линковка

Библиотека состоит из **103 модулей** — каждая функция скомпилирована в отдельный объектный файл. Линковщик включает в исполняемый файл только те функции, которые реально используются программой. Это помогает экономить память: в стандартной конфигурации код занимает одно 16 КБ окно (WIN2), хотя Sprinter располагает 4 МБ RAM и поддерживает банкинг для более крупных программ.

### Примеры

SDK включает **15 готовых примеров** с Makefile -- от "Hello World" до запуска дочерних программ через EXEC с диагностикой ошибок. Каждый пример можно собрать одной командой `make`.
