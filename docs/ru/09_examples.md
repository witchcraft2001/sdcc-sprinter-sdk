# Примеры

SDK включает 21 готовый пример, демонстрирующий различные возможности -- от простейшего "Hello World" до графики, запуска дочерних программ через EXEC, работы с APPINFO, ENVIRON и косвенных вызовов.

## Сборка и запуск

### Сборка всех примеров

```bash
cd sdcc-sprinter-sdk
make            # сначала собрать библиотеку
make examples   # затем собрать все примеры
```

### Сборка одного примера

```bash
cd examples/01_hello
make SDK_DIR=../../
```

или из корня SDK:

```bash
make -C examples/01_hello SDK_DIR=$(pwd)/
```

### Запуск

Скопируйте файл `.exe` на диск Sprinter (реальный или эмулятор) и выполните из командной строки DSS:

```
A:\>HELLO.EXE
```

## Описание примеров

### 01_hello -- Hello World

Минимальная программа, использующая прямые вызовы DSS. Демонстрирует `dss_puts` и `dss_waitkey`.

```c
#include <sprinter.h>

void main(void) {
    dss_puts("Hello from ZX Sprinter!\r\n");
    dss_puts("SDCC SDK v1.0\r\n");
    dss_puts("\r\n");
    dss_puts("Press any key to exit...\r\n");
    dss_waitkey();
}
```

**Размер: 681 байт** -- минимум, достижимый для Си-программы.

### 02_files -- Файловый ввод-вывод DSS

Демонстрирует низкоуровневую работу с файлами: `dss_creat`, `dss_write`, `dss_open`, `dss_read`, `dss_close`, `dss_delete`.

### 03_graphics -- Графика 320x256

Переключается в графический режим, устанавливает палитру GRAF, рисует цветовые полосы, рамку и диагональный градиент.

Ключевые моменты:
- `video_setmode(VMODE_320)` -- установка графического режима
- `bios_putpixel(x, y, color)` -- рисование точки
- `video_safe_porty()` -- обязательный сброс PORT_Y после рисования
- `video_setmode(VMODE_TEXT80)` -- возврат в текстовый режим

### 04_mouse -- Работа с мышью

Инициализирует драйвер мыши, устанавливает границы, показывает курсор и в цикле выводит координаты и состояние кнопок.

```c
mouse_init();                  /* Инициализация */
mouse_xbound(0, 319);         /* Границы по X */
mouse_ybound(0, 255);         /* Границы по Y */
mouse_show();                  /* Показать курсор */

while (1) {
    mouse_stat(&ms);           /* Получить состояние */
    /* ms.x, ms.y, ms.buttons */
    if (ms.buttons & MS_BTN_RIGHT)
        break;
}

mouse_hide();                  /* Скрыть курсор */
```

### 05_keyinput -- Клавиатура и системная информация

Выводит версию BIOS, дату и время, затем в цикле отображает коды нажатых клавиш.

### 06_printf -- Форматированный вывод

Демонстрирует возможности `printf`: целые числа, шестнадцатеричный вывод, строки.

```c
#include <stdio.h>

void main(void) {
    int num = 2004;
    printf("Hello world!\n");
    printf("Year: %d\n", num);
    printf("Hex: 0x%X\n", num);
    printf("String: %s\n", "test");
    puts("\nPress any key...");
    getchar();
}
```

### 07_fileio -- Стандартный файловый ввод-вывод

Работа с файлами через стандартные функции `fopen`, `fwrite`, `fread`, `fclose`, `remove`.

### 08_sort -- Алгоритмы сортировки

Портирование SORT2.C из SOLID C. Реализует три алгоритма сортировки (Bubble, Shell, Quick) и собирает статистику: количество итераций, обменов, сравнений.

Этот пример особенно полезен как образец портирования из SOLID C (см. [07 -- Перенос с SOLID C](07_перенос_с_solidc.md)).

### 09_dirlist -- Листинг каталога

Выводит список файлов текущего каталога через `dss_ffirst` / `dss_fnext`.

```c
#include <stdio.h>
#include <sprinter/dss.h>

void main(void) {
    dss_find_t entry;
    printf("Directory listing: *.*\n\n");
    if (dss_ffirst("*.*", &entry, 0x20) == 0) {
        do {
            printf("%s\n", entry.ff_name);
        } while (dss_fnext(&entry) == 0);
    }
    printf("\nDone. Press any key.\n");
    getchar();
}
```

### 10_bin2c -- Конвертер бинарных файлов

Утилита для преобразования бинарного файла в Си-массив байт (`unsigned char data[] = { ... }`). Полезно для встраивания ресурсов (шрифты, спрайты) в код.

### 11_fprintf -- Форматированный вывод в файл

Демонстрирует `fprintf` для записи форматированных данных в файл и `fgets` для их обратного чтения.

### 12_strings -- Работа со строками

Демонстрирует функции `string.h` (strlen, strcpy, strcmp, strcat, memcpy, memset) и `ctype.h` (isalpha, isdigit, toupper, tolower).

### 13_random -- Генерация случайных чисел

Демонстрирует функции `stdlib.h`: генератор псевдослучайных чисел (`rand`/`srand`), преобразование строки в число (`atoi`), абсолютное значение (`abs`).

### 14_bench -- Кросс-компиляторный бенчмарк

Запускает набор тестов, портированных из SOLID C (sieve, сортировки, CRC-16, RC4 и др.) для сравнения производительности и размера кода.

### 15_exec -- EXEC и обработка ошибок

Пример запуска дочерней программы через `dss_exec_ex()` с выводом:
- кода завершения дочерней программы (успех), или
- точного кода ошибки DSS из регистра `A` (ошибка запуска).

```c
#include <stdio.h>
#include <sprinter.h>

void main(void) {
    u8 err;
    i16 rc = dss_exec_ex("CHILD.EXE arg1", &err);
    if (rc < 0)
        printf("EXEC error: A=0x%X (%u)\n", (u16)err, (u16)err);
    else
        printf("Код завершения дочерней программы: %d\n", rc);
}
```

### 16_appinfo -- APPINFO и разбор пути

Показывает параметры программы, каталог и полный путь через `dss_appinfo()`, затем разбирает путь через `fnsplit()` и `dss_expath()`.

### 17_envdir -- Переменные окружения и каталоги

Проверяет `putenv()` / `getenv()`, создаёт временный каталог, заходит в него, возвращается назад и удаляет его.

### 18_call -- Косвенные вызовы

Вызывает обычные C-функции через `dss_call()` и `dss_callp()` и печатает возвращённые значения.

### 19_console -- Окно консоли и состояние видео

Показывает текущий видеорежим DSS, повторно применяет его, очищает текстовое окно и прокручивает его.

### 20_gfxst -- Статические спрайты gfx.lib

Демонстрирует отдельную библиотеку `gfx.lib`: спрайты фиксированного размера 8x8, 16x16 и 24x24, прозрачный цвет `0xFF`, вывод на оба графических экрана, `GFX_VRAM_ONLY` и восстановление фона из теневой страницы.

Ожидаемый вывод: чёрный графический экран с белой рамкой, красным залитым прямоугольником в нижней левой части, тонкой серой диагональной линией, толстой синей диагональю, белой окружностью в нижней правой части и четырьмя небольшими X/cross-спрайтами. После первого нажатия клавиши правый временный спрайт восстанавливается из теневой страницы; после второго нажатия пример возвращается в текстовый режим.

### 21_gfx_resources -- PNG-ресурсы gfx.lib

Показывает подготовку ресурсов через `tools/png2gfx.py`, генерацию `.gfx` и `res.h`, загрузку файла в страничную память, установку общей палитры через `video_setpal_range()` и вывод ресурса по ID.

Ожидаемый вывод: чёрный графический экран с двумя X/cross-спрайтами, загруженными из `GFXDEMO.GFX`. После вывода пример переключается на скопированный графический экран, затем по следующему нажатию возвращается обратно.

## Создание своего примера

### Ограничение имён файлов на целевой платформе

DSS не поддерживает long filenames. Любой файл, копируемый в целевой floppy image, должен иметь DOS-имя 8.3: до 8 символов в имени и до 3 символов в расширении. Это относится к EXE примеров, `.gfx`-ресурсам, сгенерированным ассетам и любым data-файлам, которые программа открывает во время выполнения. `scripts/make_floppy.sh` проверяет deployable `.exe` и `.gfx` файлы и завершает сборку с ошибкой, если найдено длинное имя.

### 1. Создайте каталог

```bash
mkdir examples/20_myapp
```

### 2. Создайте исходный файл

Файл `examples/20_myapp/main.c`:

```c
#include <stdio.h>

void main(void) {
    printf("My first Sprinter program!\n");
    getchar();
}
```

### 3. Создайте Makefile

Файл `examples/20_myapp/Makefile`:

```makefile
APP      = myapp
SRCS     = main.c
SDK_DIR  ?= ../../
include $(SDK_DIR)examples/common.mk
```

### 4. Соберите

```bash
cd examples/20_myapp
make SDK_DIR=../../
```

Результат: `myapp.exe` -- готовый исполняемый файл для Sprinter.

### Проект вне дерева SDK

Создать проект можно в любом каталоге -- достаточно указать путь к SDK:

```makefile
APP      = myapp
SRCS     = main.c utils.c
SDK_DIR  = /path/to/sdcc-sprinter-sdk/
include $(SDK_DIR)examples/common.mk
```

```bash
make
```
